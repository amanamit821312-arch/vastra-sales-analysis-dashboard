# vastra-sales-analysis-dashboard
Excel-based sales analysis and interactive dashboard for vastra Store, providing insights into sales performance, customer trends, and business growth.

## Project Overview

This project presents a comprehensive sales analysis and interactive dashboard for Vastra Store using Microsoft Excel. The dashboard helps visualize key business metrics, sales performance, customer behavior, and product trends to support data-driven decision-making.

## Objectives

* Analyze overall sales performance.
* Identify top-performing products and categories.
* Track revenue and order trends.
* Understand customer purchasing patterns.
* Generate actionable business insights.

## Dataset

The dataset contains sales transaction records, including:

* Order ID
* Order Date
* Product Category
* Product Name
* Customer Details
* Quantity Sold
* Sales Amount
* Region/Location

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Conditional Formatting
* Dashboard Design Techniques

## Dashboard Features

* Total Sales KPI
* Total Orders KPI
* Sales Trend Analysis
* Category-wise Sales Performance
* Top Products Analysis
* Regional Sales Distribution
* Interactive Filters and Slicers

## Key Insights

* Identified top-selling products and categories.
* Analyzed monthly and yearly sales trends.
* Compared regional sales performance.
* Highlighted opportunities for business growth.

## Repository Structure

* Dataset/ – Raw Excel data files
* Dashboard/ – Excel dashboard workbook
* Report/ – Project report PDF
* Presentation/ – PowerPoint presentation
* Screenshots/ – Dashboard screenshots

## Conclusion

The Vastra Store Sales Dashboard transforms raw sales data into meaningful insights, enabling better business decisions through interactive visualizations and performance tracking.
